# Trabajos Practicos de JavaScript

Carpeta de practica con cuatro trabajos de JavaScript.

## Como ejecutar
1. Abrir la carpeta del TP en VS Code.
2. Abrir `index.html` en el navegador.
3. Abrir la consola con F12 para ver resultados.

Los ejercicios estan escritos de forma simple para poder estudiarlos y explicarlos.
